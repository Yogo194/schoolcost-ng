# SchoolCost NG — Agent Rules

## Deployment

- **Never push to production without explicit instruction.** Pushing to
  `main` on GitHub auto-deploys to Vercel production. Do not `git push`
  (or merge to `main`) unless the user explicitly asks in the current
  conversation. Local commits are fine; the push is the line.
- "Commit" does not mean "deploy". When work is done, commit locally and
  tell the user it is ready to push — then wait.
